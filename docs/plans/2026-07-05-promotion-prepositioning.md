## Task 4: Annual donor certificates (constancia anual de donaciones)

Product goal: a yearly per-donor certificate (constancia) listing their ACCEPTED donations, PDF attached, emailed to the donor — the document donors need for their own tax deduction.

Paged reads (500), following the retention repository style.
2. **PDF** (src/worker/services/certificate.ts or extend pdf.ts): reuse the existing PDF generation utilities/style from src/worker/services/pdf.ts (same fonts/branding/logo). Content: emitter identity (from EMISOR_CONFIG_JSON), title "Constancia de Donaciones <year>", donor name, table of donations (fecha dd/mm/yyyy, número de control, monto), total row, issue date, and the legal-ish footer "Documento informativo emitido por <emisor>. Los CDE individuales constituyen los comprobantes fiscales." — NO MH seal claims (this is not a DTE).
3. **Email**: subject `Constancia de donaciones <year>`, branded HTML via the emailHtml frame (greeting, year total, attachment note), PDF attached, through the existing EmailService provider chain; audit `DONOR_CERTIFICATE_SENT` / `DONOR_CERTIFICATE_FAILED` per donor (entityId = donor email), dedupe like alerts: skip donors with an existing DONOR_CERTIFICATE_SENT audit for that year (entityId `<year>:<email>`) so re-runs only cover failures/new donors.
